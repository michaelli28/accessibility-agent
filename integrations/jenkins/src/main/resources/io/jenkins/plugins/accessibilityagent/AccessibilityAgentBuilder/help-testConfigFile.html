Path to a file containing accessibility tests to run. The file can be in one of two formats:

JSON Format

[
  {"url": "https://example.com", "goal": "Navigate to the login form and verify it is accessible"},
  {"url": "https://example.com/products", "goal": "Browse products using only keyboard navigation"}
]

Text Format (pipe-delimited)

# Comments start with #
https://example.com|Navigate to the login form and verify it is accessible
https://example.com/products|Browse products using only keyboard navigation

Each test will be run by the AI accessibility agent, which simulates a screen reader user navigating your website.
